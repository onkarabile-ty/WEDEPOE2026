# WEDEPOE2026

1. Project Overview
Press & Wash is a laundry business website designed to provide customers with information about the business, its services, prices and contact details.

The website aims to make it easier for customers to learn about the laundry services and get in touch with the business.
2. Website Pages
The website consists of five main pages:

1. Home Page (index.html)
- Introduces the Press & Wash business.
- Displays a welcome message.
- Provides links to services and contact information.
- Shows the main features of the business.
2. About Us Page (about.html)
- Provides information about the business.
- Explains the purpose and goals of Press & Wash.
- Describes the business's commitment to customer satisfaction.
3. Services and Prices Page (services.html)

Displays the laundry services offered, including:
- Washing clothes.
- Pressing clothes.
- Washing blankets.
- Washing curtains and other household fabrics.
The prices are:
- Standard price: R250 per basket or plastic bag.
- Discounted price: R150 per basket or plastic bag for elderly and disabled customers.
4. Gallery Page (gallery.html)
- Displays pictures of the laundry business.
- Shows laundry equipment and services.
- Allows users to click on pictures to view them in a larger size.
5. Contact Page (contact.html)

Provides the business contact information:
- Phone: +27 65 383 4837
- Email: pressandwash@gmail.com
- WhatsApp contact link.
- Google Maps location link.
3. Technologies Used
The website was developed using the following technologies:
- HTML5: Used to create the structure and content of the website.
- CSS3: Used to design the website, including colours, layouts, fonts and responsiveness.
- JavaScript: Used to add interactive features such as the mobile navigation menu and image gallery.
4. Website Features
The website includes:
- Responsive design for computers and mobile devices.
- Navigation menu linking all five pages.
- Professional blue and teal colour scheme.
- Service and price information.
- Image gallery with an enlarged image feature.
- Clickable telephone and email links.
- WhatsApp contact link.
- Google Maps location link.

6. How to Open the Website
1. Open the project folder.
2. Locate the index.html file.
3. Double-click index.html.
4. The website will open in your web browser.
5. Use the navigation menu to visit the different pages.
The website can also be opened and edited using Visual Studio Code or NetBeans.
7. Conclusion
The Press & Wash website provides a simple and professional online platform for the laundry business. It helps customers understand the services offered, view prices, explore pictures of the business and contact the company.
